## 2. Приложения ВНУТРИ Kubernetes кластера

### Вариант A: Через HAProxy на хосте (рекомендуется)

**Host IP:** `192.168.150.1` (virbr1 gateway - доступен из K8s pods)

```yaml
# application.yaml
env:
  - name: CLICKHOUSE_HOST
    value: "192.168.150.1"  # HAProxy на хосте
  - name: CLICKHOUSE_PORT
    value: "9000"           # Native протокол
  - name: CLICKHOUSE_HTTP_PORT
    value: "8123"           # HTTP протокол
```

**Connection strings:**
```bash
# Native (быстрее)
clickhouse://192.168.150.1:9000/default

# HTTP
http://192.168.150.1:8123/

# Python example
client = Client(host='192.168.150.1', port=9000)

# JDBC
jdbc:clickhouse://192.168.150.1:9000/default
```

### Вариант B: Напрямую к нодам (без балансировки)

```yaml
env:
  - name: CLICKHOUSE_HOSTS
    value: "192.168.150.140,192.168.150.141,192.168.150.142"
  - name: CLICKHOUSE_PORT
    value: "9000"
```

Приложение само делает балансировку (если драйвер поддерживает).

## 3. Приложения СНАРУЖИ (вне bare metal)

### Вариант A: Через публичный IP + HAProxy

**Public IP:** `37.27.173.224` (внешний IP сервера)

```bash
# Connection string
clickhouse://37.27.173.224:9000/default
http://37.27.173.224:8123/
```

**⚠️ ВАЖНО:** Открыть порты в firewall:
```bash
# На bare metal сервере
iptables -A INPUT -p tcp --dport 8123 -j ACCEPT
iptables -A INPUT -p tcp --dport 9000 -j ACCEPT
iptables-save > /etc/iptables/rules.v4
```

### Вариант B: SSH туннель (безопаснее)

Если не хочешь открывать порты наружу:

```bash
# Создать SSH туннель с локальной машины
ssh -L 9000:127.0.0.1:9000 -L 8123:127.0.0.1:8123 root@37.27.173.224

# Теперь подключаться к localhost
clickhouse-client --host 127.0.0.1 --port 9000
http://127.0.0.1:8123/play
```

## Примеры для разработчиков

### Python (clickhouse-driver)

```python
from clickhouse_driver import Client

# Через HAProxy (рекомендуется)
client = Client(
    host='192.168.150.1',  # Внутри K8s
    port=9000,
    database='default'
)

# Или снаружи
client = Client(
    host='37.27.173.224',
    port=9000,
    database='default'
)

# Запрос
result = client.execute('SELECT * FROM test.replication_test')
```

### Python (HTTP)

```python
import requests

# Внутри K8s
url = 'http://192.168.150.1:8123/'

# Снаружи
url = 'http://37.27.173.224:8123/'

# Запрос
response = requests.post(url, data='SELECT * FROM test.replication_test')
print(response.text)
```

### Java (JDBC)

```java
// Внутри K8s
String url = "jdbc:clickhouse://192.168.150.1:9000/default";

// Снаружи
String url = "jdbc:clickhouse://37.27.173.224:9000/default";

Connection conn = DriverManager.getConnection(url);
```

### Go (clickhouse-go)

```go
import "github.com/ClickHouse/clickhouse-go/v2"

// Внутри K8s
conn, err := clickhouse.Open(&clickhouse.Options{
    Addr: []string{"192.168.150.1:9000"},
    Auth: clickhouse.Auth{
        Database: "default",
        Username: "default",
        Password: "",
    },
})

// Снаружи - тот же код, просто другой Addr
conn, err := clickhouse.Open(&clickhouse.Options{
    Addr: []string{"37.27.173.224:9000"},
})
```

### Node.js

```javascript
const { ClickHouse } = require('clickhouse');

// Внутри K8s
const clickhouse = new ClickHouse({
  url: 'http://192.168.150.1',
  port: 8123,
  basicAuth: null,
  format: "json"
});

// Снаружи
const clickhouse = new ClickHouse({
  url: 'http://37.27.173.224',
  port: 8123
});

// Запрос
clickhouse.query('SELECT * FROM test.replication_test').toPromise()
  .then(data => console.log(data));
```

## Kubernetes ConfigMap пример

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: clickhouse-config
data:
  CLICKHOUSE_HOST: "192.168.150.1"
  CLICKHOUSE_PORT: "9000"
  CLICKHOUSE_HTTP_PORT: "8123"
  CLICKHOUSE_DATABASE: "default"
  CLICKHOUSE_USER: "default"
  # CLICKHOUSE_PASSWORD: ""  # Лучше через Secret
```

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: clickhouse-secret
type: Opaque
stringData:
  password: "clickhouse123"  # Измени на свой пароль
```

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  template:
    spec:
      containers:
      - name: app
        image: my-app:latest
        envFrom:
        - configMapRef:
            name: clickhouse-config
        env:
        - name: CLICKHOUSE_PASSWORD
          valueFrom:
            secretKeyRef:
              name: clickhouse-secret
              key: password
```

## Проверка доступности

### Из K8s pod:

```bash
# Запустить тестовый pod
kubectl run -it --rm debug --image=alpine --restart=Never -- sh

# В pod установить clickhouse-client
apk add --no-cache clickhouse-client

# Проверить подключение
clickhouse-client --host 192.168.150.1 --port 9000 --query "SELECT version()"
```

### С локальной машины (вне сервера):

```bash
# Прямое подключение (если порт открыт)
clickhouse-client --host 37.27.173.224 --port 9000 --query "SELECT 1"

# Или через SSH туннель
ssh -L 9000:127.0.0.1:9000 root@37.27.173.224
clickhouse-client --host 127.0.0.1 --query "SELECT 1"
```

## Рекомендации

✅ **Для приложений в K8s:** Используй `192.168.150.1:9000` (HAProxy на gateway)
✅ **Для UI:** Используй `http://37.27.173.224:8123/play`
✅ **Для внешних приложений:** Используй `37.27.173.224:9000` или SSH туннель
✅ **Протокол:** Native (9000) быстрее чем HTTP (8123)
✅ **Безопасность:** Настрой пароли в production (см. users.xml)

⚠️ **Не рекомендуется:** Прямое подключение к нодам 192.168.150.140-142 (без балансировки)
