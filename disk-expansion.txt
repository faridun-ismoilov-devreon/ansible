# Disk Expansion Guide (Zero Downtime)

## Преимущества 3-х нод кластера

✅ **Zero downtime** - расширяем по одной ноде, кластер работает
✅ **Online resize** - qcow2 поддерживает расширение на лету
✅ **Безопасно** - данные реплицированы на других нодах

---

## Процесс расширения

### Этап 1: ch-node-01 (пока остальные ноды работают)

#### На хосте (bare metal):
```bash
# 1. Текущий размер
qemu-img info /var/lib/libvirt/images/ch-node-01.qcow2 | grep "virtual size"

# 2. Расширить диск (100GB → 200GB)
qemu-img resize /var/lib/libvirt/images/ch-node-01.qcow2 200G

# Проверить
qemu-img info /var/lib/libvirt/images/ch-node-01.qcow2 | grep "virtual size"
```

#### В VM (ch-node-01):
```bash
ssh root@192.168.150.140

# 1. Проверить текущий размер
df -h /
lsblk

# 2. Rescan диска (чтобы VM увидела новый размер)
echo 1 > /sys/class/block/vda/device/rescan

# 3. Посмотреть layout партиций
lsblk
parted /dev/vda print

# 4. Расширить партицию (последнюю, обычно vda3 или vda4)
# Для Ubuntu 24.04 cloud-image обычно используется LVM
lvdisplay  # проверить есть ли LVM

# Если LVM:
pvresize /dev/vda3  # или номер LVM partition
lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
resize2fs /dev/ubuntu-vg/ubuntu-lv

# Если обычная партиция (без LVM):
growpart /dev/vda 3  # номер партиции
resize2fs /dev/vda3  # для ext4

# 5. Проверить новый размер
df -h /
lsblk
```

#### Проверка ClickHouse:
```bash
# ClickHouse продолжал работать всё время!
clickhouse-client --host 192.168.150.140 --user admin --password clickhouse_admin_2024 --query "SELECT formatReadableSize(free_space), formatReadableSize(total_space) FROM system.disks"
```

## Проверка доступного места

### В ClickHouse:
```sql
-- Общее и свободное место на дисках
SELECT 
    name,
    path,
    formatReadableSize(total_space) AS total,
    formatReadableSize(free_space) AS free,
    round(free_space / total_space * 100, 2) AS free_percent
FROM system.disks;

-- По базам данных
SELECT 
    database,
    formatReadableSize(sum(bytes_on_disk)) AS size_on_disk,
    formatReadableSize(sum(data_uncompressed_bytes)) AS uncompressed_size
FROM system.parts
WHERE active
GROUP BY database
ORDER BY sum(bytes_on_disk) DESC;
```

### В OS:
```bash
# Диск
df -h /

# LVM (если используется)
lvs
vgs
pvs
```

## Script для автоматизации

```bash
#!/bin/bash
# expand-disk.sh

VM_NAME=$1
NEW_SIZE=$2  # например: 200G

if [ -z "$VM_NAME" ] || [ -z "$NEW_SIZE" ]; then
    echo "Usage: $0 <vm_name> <new_size>"
    echo "Example: $0 ch-node-01 200G"
    exit 1
fi

DISK_PATH="/var/lib/libvirt/images/${VM_NAME}.qcow2"

# 1. Backup current size
CURRENT_SIZE=$(qemu-img info $DISK_PATH | grep "virtual size" | awk '{print $3$4}')
echo "Current size: $CURRENT_SIZE"

# 2. Resize
echo "Resizing to $NEW_SIZE..."
qemu-img resize $DISK_PATH $NEW_SIZE

# 3. Verify
NEW_SIZE_CHECK=$(qemu-img info $DISK_PATH | grep "virtual size" | awk '{print $3$4}')
echo "New size: $NEW_SIZE_CHECK"

echo ""
echo "Next steps:"
echo "1. SSH to VM"
echo "2. Run: echo 1 > /sys/class/block/vda/device/rescan"
echo "3. Expand partition and filesystem (see disk-expansion.txt)"
```

## Мониторинг места

### Настроить алерты (рекомендуется):

```sql
-- Если свободного места < 20% - пора расширять
SELECT 
    hostName(),
    round(free_space / total_space * 100, 2) AS free_percent
FROM system.disks
WHERE free_percent < 20;
```

### Cron job для мониторинга:
```bash
# Каждый день проверять место
0 9 * * * clickhouse-client --host 192.168.150.140 --user admin --password clickhouse_admin_2024 --query "SELECT hostName(), formatReadableSize(free_space) FROM system.disks" | mail -s "ClickHouse Disk Space" admin@domain.com
```

## FAQ

**Q: Можно ли уменьшить диск?**
A: Нет, qcow2 не поддерживает shrink. Только расширение.

**Q: Нужна ли перезагрузка VM?**
A: Нет! Все операции онлайн.

**Q: Остановится ли ClickHouse?**
A: Нет! Благодаря репликации кластер продолжает работать.

**Q: Как часто можно расширять?**
A: Сколько угодно раз. Каждый раз онлайн.

**Q: Есть ли лимит размера?**
A: Лимит qcow2 = 2TB виртуального диска (достаточно для большинства случаев)

**Q: Что если закончится место на хосте?**
A: Тогда проблема. Мониторь место на хосте: `df -h /var/lib/libvirt/images`
