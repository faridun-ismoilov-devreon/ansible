# Kafka Connection Guide (SASL/SCRAM-SHA-256)

## Available Ports

| Port | Protocol | Authentication | Usage |
|------|----------|----------------|-------|
| 9092 | PLAINTEXT | None | Internal/Monitoring only |
| 9094 | SASL_PLAINTEXT | SCRAM-SHA-256 | **Applications (USE THIS)** |
| 9093 | CONTROLLER | Internal | KRaft controller |

## Credentials

### Admin User
- **Username**: `admin`
- **Password**: `admin-secret-password`
- **Permissions**: Full access

### Application User
- **Username**: `kafka-app`
- **Password**: `app-secret-password`
- **Permissions**: Standard producer/consumer

## Connection Strings

### Internal (from OKD pods)
```
bootstrap.servers=192.168.150.150:9094,192.168.150.151:9094,192.168.150.152:9094
security.protocol=SASL_PLAINTEXT
sasl.mechanism=SCRAM-SHA-256
sasl.jaas.config=org.apache.kafka.common.security.scram.ScramLoginModule required username="kafka-app" password="app-secret-password";
```

## Client Examples

### Python (kafka-python)
```python
from kafka import KafkaProducer

producer = KafkaProducer(
    bootstrap_servers=['192.168.150.150:9094'],
    security_protocol='SASL_PLAINTEXT',
    sasl_mechanism='SCRAM-SHA-256',
    sasl_plain_username='kafka-app',
    sasl_plain_password='app-secret-password'
)

producer.send('my-topic', b'Hello Kafka')
producer.flush()
```

### Java
```java
Properties props = new Properties();
props.put("bootstrap.servers", "192.168.150.150:9094");
props.put("security.protocol", "SASL_PLAINTEXT");
props.put("sasl.mechanism", "SCRAM-SHA-256");
props.put("sasl.jaas.config", 
    "org.apache.kafka.common.security.scram.ScramLoginModule required " +
    "username=\"kafka-app\" " +
    "password=\"app-secret-password\";");

Producer<String, String> producer = new KafkaProducer<>(props);
```

### Go (sarama)
```go
config := sarama.NewConfig()
config.Net.SASL.Enable = true
config.Net.SASL.Mechanism = sarama.SASLTypeSCRAMSHA256
config.Net.SASL.User = "kafka-app"
config.Net.SASL.Password = "app-secret-password"

brokers := []string{"192.168.150.150:9094"}
producer, err := sarama.NewSyncProducer(brokers, config)
```

### Node.js (kafkajs)
```javascript
const { Kafka } = require('kafkajs');

const kafka = new Kafka({
  clientId: 'my-app',
  brokers: ['192.168.150.150:9094'],
  sasl: {
    mechanism: 'scram-sha-256',
    username: 'kafka-app',

```

## Testing Connection

### 1. From Kafka node (internal)
```bash
# Using SASL port
/opt/kafka/bin/kafka-console-producer.sh \
  --bootstrap-server localhost:9094 \
  --topic test-topic \
  --producer-property security.protocol=SASL_PLAINTEXT \
  --producer-property sasl.mechanism=SCRAM-SHA-256 \
  --producer-property 'sasl.jaas.config=org.apache.kafka.common.security.scram.ScramLoginModule required username="kafka-app" password="app-secret-password";'
```

### 2. From OKD pod
```bash
kubectl run kafka-test --rm -it --image=confluentinc/cp-kafka:latest -- bash

  --consumer-property 'sasl.jaas.config=org.apache.kafka.common.security.scram.ScramLoginModule required username="kafka-app" password="app-secret-password";'
```

## User Management

### List users
```bash
/opt/kafka/bin/kafka-configs.sh --bootstrap-server localhost:9092 \
  --describe --entity-type users
```

### Add new user
```bash
/opt/kafka/bin/kafka-configs.sh --bootstrap-server localhost:9092 \
  --alter --add-config 'SCRAM-SHA-256=[password=new-password]' \
  --entity-type users --entity-name new-username
```

### Delete user
```bash
/opt/kafka/bin/kafka-configs.sh --bootstrap-server localhost:9092 \
  --alter --delete-config 'SCRAM-SHA-256' \
  --entity-type users --entity-name username-to-delete
```

## Security Notes

⚠️ **Important:**
1. Port 9092 (PLAINTEXT) should only be used for:
   - Inter-broker communication
   - Monitoring (Prometheus)
   - Internal admin tasks
2. **All applications** should use port **9094** with SASL authentication
3. Change default passwords in production!
4. Consider using SSL/TLS (SASL_SSL) for encryption in transit
