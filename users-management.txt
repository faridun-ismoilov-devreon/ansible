## Подключение с admin

### CLI
```bash
# Прямо к ноде
clickhouse-client --host 192.168.150.140 --user admin --password clickhouse_admin_2024

# Через HAProxy
clickhouse-client --host 37.27.173.224 --user admin --password clickhouse_admin_2024

# Из K8s
clickhouse-client --host 192.168.150.1 --user admin --password clickhouse_admin_2024
```

### HTTP
```bash
# С паролем в URL
curl 'http://admin:clickhouse_admin_2024@37.27.173.224:8123/?query=SELECT+1'

# С Basic Auth
curl -u admin:clickhouse_admin_2024 'http://37.27.173.224:8123/?query=SELECT+1'
```

### Python
```python
from clickhouse_driver import Client

client = Client(
    host='192.168.150.1',
    port=9000,
    user='admin',
    password='clickhouse_admin_2024'
)

result = client.execute('SELECT 1')
```

## Создание других пользователей

### Через конфигурационный файл (рекомендуется)

**Создать файл `/etc/clickhouse-server/users.d/app_user.xml` на всех нодах:**

```xml
<clickhouse>
    <users>
        <!-- Application user -->
        <app_user>
            <password>app_password_123</password>
            <networks>
                <ip>::/0</ip>
            </networks>
            <profile>default</profile>
            <quota>default</quota>
        </app_user>
        
        <!-- Read-only user -->
        <readonly_user>
            <password>readonly_pass_123</password>
            <networks>
                <ip>::/0</ip>
            </networks>
            <profile>readonly</profile>
            <quota>default</quota>
        </readonly_user>
    </users>
    
    <!-- Readonly profile -->
    <profiles>
        <readonly>
            <readonly>1</readonly>
            <max_memory_usage>5000000000</max_memory_usage>
        </readonly>
    </profiles>
</clickhouse>
```

**Применить на всех нодах:**
```bash
# На каждой ноде
ssh root@192.168.150.140 'cat > /etc/clickhouse-server/users.d/app_user.xml' << 'EOF'
# ... содержимое выше
EOF

# Перезагрузить конфигурацию
clickhouse-client --host 192.168.150.140 --query 'SYSTEM RELOAD CONFIG'
```

---

### Через SQL (если включен access_management)

```sql
-- Создать пользователя
CREATE USER app_user IDENTIFIED WITH plaintext_password BY 'app_password_123';

-- Дать права на конкретную БД
GRANT SELECT, INSERT, CREATE TABLE ON mydb.* TO app_user;

-- Или все права
GRANT ALL ON *.* TO app_user;

-- Создать read-only пользователя
CREATE USER readonly_user IDENTIFIED WITH plaintext_password BY 'readonly_pass_123';
GRANT SELECT ON *.* TO readonly_user;

-- Посмотреть пользователей
SHOW USERS;

-- Посмотреть права
SHOW GRANTS FOR app_user;

-- Удалить пользователя
DROP USER app_user;
```

## Автоматическое создание на всех нодах

**Скрипт для создания пользователя:**

```bash
#!/bin/bash
# create-clickhouse-user.sh

USERNAME=$1
PASSWORD=$2

if [ -z "$USERNAME" ] || [ -z "$PASSWORD" ]; then
    echo "Usage: $0 <username> <password>"
    exit 1
fi

for IP in 140 141 142; do
  ssh root@192.168.150.$IP "cat > /etc/clickhouse-server/users.d/${USERNAME}.xml" << USERXML
<clickhouse>
    <users>
        <${USERNAME}>
            <password>${PASSWORD}</password>
            <networks>
                <ip>::/0</ip>
            </networks>
            <profile>default</profile>
            <quota>default</quota>
        </${USERNAME}>
    </users>
</clickhouse>
USERXML
  
  echo "User created on 192.168.150.$IP"
done

# Reload config
clickhouse-client --host 192.168.150.140 --query 'SYSTEM RELOAD CONFIG'
clickhouse-client --host 192.168.150.141 --query 'SYSTEM RELOAD CONFIG'
clickhouse-client --host 192.168.150.142 --query 'SYSTEM RELOAD CONFIG'

echo "User $USERNAME created on all nodes!"
```

**Использование:**
```bash
chmod +x create-clickhouse-user.sh
./create-clickhouse-user.sh app_user app_password_123
```

## SHA256 пароль (безопаснее)

Вместо plaintext пароля можно использовать SHA256:

```bash
# Сгенерировать SHA256 хеш
echo -n 'my_password' | sha256sum
# Результат: 5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8

# В конфиге:
<password_sha256_hex>5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8</password_sha256_hex>
```

## Profiles (ограничения)

```xml
<profiles>
    <!-- Для приложений -->
    <app_profile>
        <max_memory_usage>10000000000</max_memory_usage>
        <max_execution_time>300</max_execution_time>
        <max_rows_to_read>10000000</max_rows_to_read>
    </app_profile>
    
    <!-- Read-only -->
    <readonly>
        <readonly>1</readonly>
        <max_memory_usage>5000000000</max_memory_usage>
        <max_execution_time>60</max_execution_time>
    </readonly>
</profiles>
```

```xml
            <duration>3600</duration>
            <queries>1000</queries>
            <errors>100</errors>
            <result_rows>1000000</result_rows>
            <read_rows>10000000</read_rows>
            <execution_time>7200</execution_time>
        </interval>
    </app_quota>
</quotas>
```

## Best Practices

✅ **Используй разные пользователи** для разных приложений
✅ **Никогда не используй default** в production
✅ **SHA256 пароли** вместо plaintext
✅ **Ограничивай сети** через `<networks>` (не `<ip>::/0</ip>`)
✅ **Используй profiles** для ограничения ресурсов
✅ **Храни пароли в Kubernetes Secrets** (не в коде)

## Смена пароля

**Через конфиг (требует перезагрузки):**
```bash
# Изменить файл users.d/admin.xml
nano /etc/clickhouse-server/users.d/admin.xml

# Перезагрузить
clickhouse-client --query 'SYSTEM RELOAD CONFIG'
```

**Через SQL (если доступно):**
```sql
ALTER USER admin IDENTIFIED BY 'new_password';
```

---

## Удаление пользователя

**Через конфиг:**
```bash
rm /etc/clickhouse-server/users.d/username.xml
clickhouse-client --query 'SYSTEM RELOAD CONFIG'
```

**Через SQL:**
```sql
DROP USER username;
```

## Kubernetes Secret пример

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: clickhouse-credentials
type: Opaque
stringData:
  username: admin
  password: clickhouse_admin_2024
  host: 192.168.150.1
  port: "9000"
```

```yaml
# В deployment
env:
- name: CLICKHOUSE_USER
  valueFrom:
    secretKeyRef:
      name: clickhouse-credentials
      key: username
- name: CLICKHOUSE_PASSWORD
  valueFrom:
    secretKeyRef:
      name: clickhouse-credentials
      key: password
```
